# Skill: bear-sync

将熊窝网站数据（任务记录 + 支出记录）同步到 Obsidian 日记。

## 触发场景

- 用户说"记一下今天做了什么"、"记录支出"、"同步到日记"
- 用户提供了某天的任务时间线或支出明细
- 用户要求编辑 `diary-data.js` 或 `data.js`

## 核心逻辑

### 数据文件

| 文件 | 内容 | 位置 |
|------|------|------|
| `js/diary-data.js` | 任务记录（diaryRecords） | `personal/` 项目内 |
| `js/data.js` | 支出记录（expenseRecords） | `personal/` 项目内 |

### 同步脚本

```bash
python3 scripts/sync-to-diary.py
```

- 读取 `diary-data.js` 和 `data.js`
- 将新记录追加到 `_diary/YYYY-MM-DD.md`（通过软链指向 Obsidian vault）
- 任务写入 `# Day planner` 段落
- 支出写入 `# 支出` 表格
- 使用 `.sync-state.json` 去重，不会重复追加

### 初始化（首次使用或重置状态）

```bash
python3 scripts/sync-to-diary.py --init
```

标记当前数据为已同步，不写入文件。

## 执行步骤

### 1. 解析用户输入

从用户描述中提取：
- **日期**：如"今天"、"7月6号"、"2026-07-06"
- **任务**：时间段 + 描述，如"14:10-18:00 网站开发"
- **支出**：金额 + 分类 + 备注，如"吃饭花了 13.5 元"

### 2. 编辑 diary-data.js（任务）

在 `diaryRecords` 对象中找到或创建对应日期的条目，追加任务：

```javascript
{
  "status": "x",
  "time": "14:10-18:00",
  "desc": "网站开发，完善猫猫网站和熊窝"
}
```

**格式要求：**
- `time` 使用 `HH:MM-HH:MM`（无空格，脚本会转换为 `HH:MM - HH:MM`）
- `desc` 可包含 `#area/xxx` 标签
- `status` 通常为 `"x"`（已完成）

### 3. 编辑 data.js（支出）

在 `expenseRecords` 数组中追加支出：

```javascript
{ date: '2026-07-06', cat: '市内出行', sub: '外出餐饮', amount: 13.50, note: '丁香食堂' }
```

**分类参考（来自 `expenseCategories`）：**

| 分类 | 子项示例 |
|------|---------|
| 居家生活 | 居家、做饭、洗漱、洗衣服、维修、快递 |
| 通讯订阅 | 通讯、话费套餐、vip |
| 形象装扮 | 服饰、美容 |
| 市内出行 | 外出餐饮、借充电宝、市内交通 |
| 娱乐消费 | 娱乐、游戏充值、抓娃娃、彩票 |
| 自我提升 | 学习、办公、运动健身 |
| 电子产品 | 数码产品、数码配件、大家电、小家电 |
| 人情社交 | 社交、亲友、节日、纪念、长辈、爸爸妈妈、孩子、宝贝 |
| 市外出行 | 跨省交通、住房、旅行中途餐饮 |
| 猫协救助 | 宠物 |
| 医疗保健 | 医疗 |

### 4. 运行同步脚本

```bash
python3 scripts/sync-to-diary.py
```

预期输出：`Synced N tasks and M expenses to _diary/`

### 5. 验证结果

读取对应的 `_diary/YYYY-MM-DD.md` 文件，确认：
- 任务已追加到 `# Day planner` 段落
- 支出已追加到 `# 支出` 表格
- 当日合计金额已自动更新

## Demo 1：记录一天的任务和支出

**用户输入：**
> 7月6号，14:10-18:00 网站开发，完善猫猫网站和熊窝。18:00-19:40 在丁香食堂吃饭，花费 13.5 元，并且去游泳。19:40-23:30 去和过马路、耿哥以及轩轩他们唱 K。23:30-24:00 回家。

**执行：**

1. 编辑 `js/diary-data.js`，在 `"2026-07-06"` 的 `tasks` 数组末尾追加：

```javascript
{
  "status": "x",
  "time": "14:10-18:00",
  "desc": "网站开发，完善猫猫网站和熊窝"
},
{
  "status": "x",
  "time": "18:00-19:40",
  "desc": "在丁香食堂吃饭，花费 13.5 元，并且去游泳"
},
{
  "status": "x",
  "time": "19:40-23:30",
  "desc": "去和过马路、耿哥以及轩轩他们唱 K"
},
{
  "status": "x",
  "time": "23:30-24:00",
  "desc": "回家"
}
```

2. 编辑 `js/data.js`，在 `expenseRecords` 数组追加：

```javascript
{ date: '2026-07-06', cat: '市内出行', sub: '外出餐饮', amount: 13.50, note: '丁香食堂' }
```

3. 运行同步：

```bash
python3 scripts/sync-to-diary.py
```

4. 验证 `_diary/2026-07-06.md`：

```markdown

...
- [x] #task 14:10 - 18:00 网站开发，完善猫猫网站和熊窝 ⏳ 2026-07-06
```

**用户输入：**

## 注意事项

- 同步是**单向追加**，不会修改或删除已有记录
- 如果日期对应的 `.md` 文件不存在，脚本会自动创建（使用标准模板结构）
- 任务时间格式在 `diary-data.js` 中用 `HH:MM-HH:MM`，同步后在 `.md` 中变为 `HH:MM - HH:MM`
- 支出分类必须从 `expenseCategories` 中选择，找不到合适分类时使用最接近的
- 多次运行同步脚本不会重复追加（通过 `.sync-state.json` 去重）
